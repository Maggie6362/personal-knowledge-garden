# 個人知識花園｜免費入門版

這是一個可放在 GitHub + Cloudflare Pages 免費靜態託管的繁體中文 Web App，優先考量 iPhone 使用、較大字體、莫蘭迪色系與卡片式介面。

## 功能
- 知識筆記：分類、搜尋、編輯與刪除；可收藏文章或 YouTube 網址並開啟原始頁面。
- 每日學習：建立今日待辦、標記完成。
- 記憶卡片：建立問答卡並標記熟悉度。
- 專注計時：15／25／45／60 分鐘選擇。
- JSON 備份與還原。
- 首頁與各功能頁可切換，避免將所有功能擠成單一長頁。

## 部署方式
1. 將 `index.html` 上傳到 GitHub 儲存庫根目錄（不要放在子資料夾）。
2. 到 Cloudflare Pages 建立專案，選擇連接 GitHub 儲存庫。
3. Framework preset 選 `None`；Build command 留空；Build output directory 設為 `/` 或 `.`（依介面提示）。
4. 部署完成後，使用 Cloudflare 提供的網址開啟網站。
5. iPhone 使用 Safari 開啟網站，點「分享」→「加入主畫面」。

## 重要提醒
- 不需要付費 API、資料庫或自訂網域，基本靜態託管可使用免費方案；服務商方案或限制可能調整，請以註冊時顯示為準。
- 資料儲存在瀏覽器 `localStorage`，不會在 iPhone 與電腦之間自動同步。
- 清除網站資料或更換瀏覽器可能造成資料遺失，請定期匯出 JSON 備份。
- 此版本不會自動擷取外部文章全文或 YouTube 逐字稿，也尚未加入雲端帳號同步或 AI API。
- 開啟收藏連結會在新分頁載入原網站。
